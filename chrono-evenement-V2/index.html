Raccourcis

Créer ou modifier un raccourci de temps

Choisissez un titre et un temps, puis « Enregistrer » : le raccourci est prêt à être utilisé.

Message à l'orateur

Raccourcis : préparer les 10 mémoires

Chaque ligne contient tout le raccourci : nom, mode, temps, format, titre, message. Modifiez ce que vous voulez puis cliquez sur « Enregistrer » : c'est prêt.

Retenir aussi, depuis l'écran actuel :
Minuteur en cours (réglage direct, sans passer par un raccourci)

Messages mémorisés

20 messages au maximum. Dans l'onglet Exploitation, un clic sur un message l'envoie et l'affiche.

Couleurs selon le temps restant (décompte)

Par défaut : vert au-dessus de 3:00, orange entre 3:00 et 0:00, rouge à zéro et pendant le dépassement. Avec « Fond », la couleur ne s'applique pas si le fond est transparent. Si le dépassement est activé, le clignotement dure 5 secondes après zéro.

Affichage du minuteur

Le fond transparent est visible tel quel dans un logiciel vidéo ou, avec la version bureau, directement à l'écran.

Message à l'orateur : placement et style

La zone se règle en pourcentage de l'écran. L'aperçu de l'onglet Exploitation montre le résultat.

Sortie : fenêtre, format et écran

Faites glisser la fenêtre de sortie sur le second écran, ou, dans la version bureau, utilisez « Plein écran » sur l'écran choisi ci-dessous.

La sortie garde ce format exact et s'adapte à la taille de la fenêtre. En plein écran sur un écran 4K, elle est diffusée en 4K.

Touche F ou double-clic dans la sortie : bascule entre plein écran et fenêtre libre.

Réseau et Stream Deck

Cette partie est disponible dans la version bureau (.exe).

Page web du chrono : à ouvrir depuis n'importe quel appareil du réseau (retour moniteur, tablette, régie).

Si une autre machine n'arrive pas à se connecter, autorisez l'application dans le pare-feu Windows (réseau privé).

Stream Deck et Companion

Avec Bitfocus Companion (recommandé) : le module fourni dans le dossier companion-module donne les actions, les retours d'état (Lancer / Pause / dépassement / couleur du seuil / message affiché) et les variables (temps, noms des mémoires). Voir LISEZ-MOI.txt.

Avec l'application Stream Deck seule : action « Système > Site web », « Accès en arrière-plan » coché, avec l'une de ces adresses. Il n'y a pas de retour d'état dans ce cas.

Touches globales possibles aussi (action « Raccourci clavier ») : F13 à F22 = raccourcis 1 à 10, F23 = lancer, F24 = pause/reprise, Ctrl+F13 = réinitialiser, Ctrl+F14 = fermer la sortie, Ctrl+F15 = afficher/masquer le message.

Import/export configuration

Paramètres, raccourcis, messages mémorisés et image de fond tiennent dans un fichier à copier sur un autre ordinateur.
